# Changelog

## 0.6.0 — 2026-11-16

- Draw every focus round on the day ribbon at its recorded active times, as a hatched span in the project's colour, whichever screen started it; a running round grows live.
- Count real focus in the u-cup alongside planned slots, and show planned and extra focus time separately.
- Drag ribbon segments to resize or move them, drag across empty time to create a block, and right-click a segment to edit or delete it.
- Add delete with a 12-second undo for tasks, time blocks, milestones and long-term projects; deleting a project keeps its focus history unlinked rather than erasing it.
- Give projects an optional tone from six coral/purple-ink shades, and show flexible daily targets with time done and time left in today's list.
- Fold two or more overdue milestones into one expandable row so upcoming ones stay visible; add a "skip this day" action to project day plans.
- Add the month overview to “这几天”, switching between a month grid and a four-day focus.
- Hide heavy scroll bars in editor sheets. 289 isolated checks pass.

## 0.5.0 — 2026-11-02

- Refresh the speaking-u wordmark, app icon and purple-ink/coral interface, with frosted cards and grouped navigation.
- Rebuild the daily workbench around the selected activity, focus controls, a daily u-cup, a single-row day ribbon, upcoming milestones and project progress.
- Give overlapping events distinct opaque tones and inset outlines so each event remains visible, including events with identical time ranges.
- Show start/end times, duration, status and a wrapping title in a dark card above the ribbon; keep edge tooltips within the track.
- Put unfinished daily blocks first while keeping completed content visible and restoring chronological order when unchecked.
- Correct overdue-task guidance for ongoing and expired preparation slots, and avoid promising system reminders when notifications are disabled.
- Add reminder-boundary and ribbon-layout regression checks; 258 isolated checks pass.

## 0.2.0 — 2026-10-27

- Timed meetings and activities now remind 15 minutes before their start and again at the start.
- Meeting links are available on timeline cards, desktop reminders and notification actions.
- Meeting snoozes stop at the start time; completion and rescheduling remove stale notifications.
- Deadline, meeting, time-block and focus notifications share bounded scheduling budgets.

## 0.1.0 — Public preview

- Quiet hover-revealed desktop note with visible completed tasks.
- Custom categories, daily time blocks, long-term deadlines and multi-day activities.
- Focus/break rounds, deadline radar, grouped cards and persistent snoozes.
- Read-only Mac Calendar integration and local preview-based email/Canvas imports.
- Latest Canvas notification publication wins when a deadline changes.
- Empty first launch, Application Support storage, isolated fictional demo and privacy checks.

This is the first public source release. It contains no personal task history, calendars or original development Git history.
