# 日期总览

仍从侧边栏“这几天”进入，用“整月总览 / 四天聚焦”切换远近，不增加侧边栏页面。

- 整月按周一到周日排列，每天有独立日期格；可前后翻月或回到今天。
- 格内随窗口高度显示两到三项安排摘要，其他显示“还有几项”。包括待办、截止、日历活动、时间块及长期项目当天投入；跨天活动在覆盖日期持续显示。
- 点击日期格，在同页展开当天的完整安排；宽窗口显示右侧详情，较窄窗口跳到下方详情，可点向上箭头回到日期格。
- 空白日期点击格内“+”或详情的“添加事项”，默认带入该日期；“安排时间”可直接建立时间块。
- 点击详情中的标题编辑；点击圆圈完成，文字划线并排到后面。事项右键菜单支持原有编辑、链接和删除撤销。
- 点击“展开当天时间轴”，在“这几天”内部复用已有的每日安排视图；“返回日期总览”回到原月和选中日期。
- 四天聚焦保留大卡片，显示事项、时间块及项目计划。点击日期进入当天时间轴；前后箭头每次移动四天。
- 搜索同时覆盖事项、时间块和项目标题；月格保留所有日期，未匹配的安排不显示，清空搜索恢复。
- 侧边栏小日历的提示点也会考虑时间块和项目当天计划。

这是日期展示与操作的扩展，没有迁移清单格式，也不会自动改动原日历、排期或专注历史。
