# 我Due！功能总览 · v0.4.0

主分支另含新版工作台与动线设计；公开安装包仍为 v0.4.0。以下标注为主分支的新界面需要从源码构建。

DDL 别丢，生活照过。把未来的目标落实为每天的安排，让已经付出的努力也看得见。

## 从收集到推进

收集日程与通知 → 识别、确认与分类 → 建立项目或截止节点 → 安排每日时间 → 专注与休息 → 查看投入和成果 → 根据实际情况调整计划。

| 模块 | 当前支持 |
| --- | --- |
| 桌面便签 | 静置时近乎透明，鼠标移入浮现底板和操作；置顶、添加事项、勾选完成。未完成在前、已完成置后且划线保留。展示最多两个项目的精简倒计时与投入摘要。 |
| 日历同步 | 读取选定的 macOS 日历，镜像最近 30 天至未来 180 天的事件。可连接由 macOS 管理的云端日历。支持本机修改标题、日期、时段、链接与备注；改过的字段不会被同步覆盖，可恢复日历版本。 |
| 邮件与活动导入 | 主动粘贴文字，在本机按格式识别日期、时间、标题、链接和备注；预览修正后保存。缺失或歧义信息需确认。 |
| Canvas 导入 | 粘贴作业、公告或作业通知；按课程与作业身份合并。可识别通知发布时间时，较新的通知决定截止更新；缺少日期、顺序不明或冲突时留待确认。支持一次性导出 .ics。 |
| 截止提醒 | 三天内突出显示，截止当天、两小时内、半小时内和逾期分级提示。桌面卡片、确认与 30 分钟稍后提醒；日期型截止不凭空补 23:59。 |
| 会议与活动提醒 | 明确开始时间的活动，在开始前 15 分钟及开始时提醒。卡片、时间轴和通知操作可打开已保存链接；支持 5 分钟稍后提醒，改期后撤换旧通知。 |
| 每日时间安排 | 自定义工作与休息时间块，关联事项或项目，显示重叠提示、留白和空档建议。支持按天查看、近期安排和全部事项。 |
| 今日工作台（主分支） | 集中显示当前/选中事项、专注操作、每日 u 杯、近期节点和项目进度。单行动线使用不同紫灰色阶与内嵌边界区分重叠事件；深色悬停卡片显示起止时间、时长、状态和可换行的完整标题。安排清单未完成在前，已完成保留划线。 |
| 长期项目 | 自定义目标与日期范围、每日投入、执行星期和默认时段；可单独调整任意一天或休息，预览总投入。项目可关联多个截止、活动或待办节点。 |
| 计划与时间轴联动 | 单日项目安排可加入时间轴；之后从项目调整该日安排，会更新未完成的对应时间块。已完成时段与历史投入保留。 |
| 项目专注累计 | 从项目或关联时间块开始专注，累计今日与整个项目的计时时长。暂停、休息与离线时间不增加投入；跨午夜按日统计，重启恢复为暂停。项目改名或未来计划修改不会抹掉历史。 |
| 番茄专注与休息 | 25/5、50/10 或自定义节奏；暂停、继续、菜单栏计时；关联时间块时在结束边界收尾。达到时长不会自动勾选事项或项目完成。 |
| 成果与持续反馈 | 同时展示倒计时、今日投入、累计投入、未来计划和可选的投入估算；可手动记录字数、章节、题数等成果数量。时间投入与成果完成分别表达。 |
| 项目日常提醒 | 每日提醒时间和提前天数可设置，默认从项目开始日提醒。项目倒计时持续可见，不局限最后三天。系统预排最近三个提醒，运行或重新打开应用会续排。 |
| 自定义与本地数据 | 类别与颜色可自定义；支持多日活动和旅行。数据本机保存，清单支持 JSON 导入导出，完整数据目录可备份专注、提醒和草稿。 |

## 功能边界

- 邮件和 Canvas 使用“主动粘贴 → 预览 → 保存”，目前不自动读取邮箱、不登录 Canvas 抓取公告，也不后台监控剪贴板。
- 云端日历变更需先同步到 macOS 日历，再由本应用读取。本机修正不会回写源日历。
- 专注累计以启动、暂停及停止计时为准，不监测用户是否真的在学习；字数等成果数量由用户记录。
- 计划由用户设置和调整，目前没有自动重排全天、跨设备任务同步、移动端或协作功能。
- 应用内卡片和日历检查需应用运行；已排定的系统通知由 macOS 管理，受通知设置、专注模式和睡眠状态影响。项目提醒需运行或定期打开以续排。

## 数据与升级

公开版首次启动为空，不含个人日程或反馈聊天截图。清单格式为版本 4，兼容读取旧清单；旧版应用无法读取新格式。项目计时保存到 focus-v2.json，原 focus.json 在迁移时保留。旧记录没有可靠项目归属时，不按标题猜测归属。

JSON 清单导出包含事项、项目、分类和时间块；完整专注历史、提醒状态和草稿需备份整个数据目录。公开版目录为 ~/Library/Application Support/io.github.amalia6767.wodue/。
