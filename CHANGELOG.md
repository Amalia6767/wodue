# Changelog

## 0.2.0 — 2026-10-27

- Timed meetings and activities now remind 15 minutes before their start and again at the start.
- Meeting links are available on timeline cards, desktop reminders and notification actions.
- Meeting snoozes stop at the start time; completion and rescheduling remove stale notifications.
- Deadline, meeting, time-block and focus notifications share bounded scheduling budgets.

## 0.1.0 — Public preview

- Quiet hover-revealed desktop note with visible completed tasks.
- Custom categories, daily time blocks, long-term deadlines and multi-day activities.
- Focus/break rounds, deadline radar, grouped cards and persistent snoozes.
- Read-only Mac Calendar integration and local preview-based email/Canvas imports.
- Latest Canvas notification publication wins when a deadline changes.
- Empty first launch, Application Support storage, isolated fictional demo and privacy checks.

This is the first public source release. It contains no personal task history, calendars or original development Git history.
