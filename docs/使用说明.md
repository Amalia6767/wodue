# 我Due！使用说明

**DDL 别丢，生活照过。**

## 开始

在 macOS 14 或更新版本上运行 `zsh scripts/build.sh`，再打开 `dist/我Due！.app`。默认构建适用于 Apple Silicon；首次启动为空清单。界面目前为中文。

“今日节奏”安排每天的工作与休息；“长期计划”放未来的提交节点、Presentation、Workshop、展会和旅行。“这几天 / 全部事项”按日期查看事项。`⌘N` 添加，点击事项前的圆圈划掉，划线后的文字继续保留。

需要看演示时运行 `zsh scripts/demo.sh`。演示使用虚构事项、独立应用身份和独立数据文件夹，并禁止连接真实日历。

## 节点、分类和准备时间

- **提交 / 截止**：作业、报名等真正的截止节点，可以填写准确时刻。
- **活动 / 行程**：Presentation、Workshop、展会或旅行。多日行程的结束日期包含所选那一天。
- **待办、休息 / 放松**：日常行动、家庭事务、娱乐与休息。
- 分类的名称和颜色都能修改，也能新增；分类与事项性质分开。删除分类不删除事项。

在节点旁点“安排时间”另排准备时段。同一事项可有多段工作，原截止日期保留。完成时间块不代表提交完成。

例如 11:00–12:00 写项目草稿、12:00–13:00 午饭、13:00–15:00 制作原型，再留一段休息。重叠安排会提示；“找下个空档”在 09:00–21:00 内按 15 分钟取整查找，今天从当前时刻之后开始。

## 透明桌面便签

平时几乎没有底色；鼠标移入时显现底板、增加文字对比度并显示添加栏和工具按钮。输入、菜单和外观设置展开时保持清楚。静置与关注时的背景浓度、文字颜色、置顶、位置和大小会记住。

便签菜单可以打开完整清单、粘贴识别、Canvas 预览、日历设置或隐藏便签。`⌥⌘M` 显示 / 隐藏。可以关闭主窗口只留便签；`⌘Q` 会退出整个应用。

系统开启“减少动态效果”时不播放淡入淡出；开启“降低透明度”时使用清晰底板。

## 三天 DDL 提醒

将事项性质设为“提交 / 截止”。没有指定性质、标题以 `DDL` / `deadline` 开头的单日事项也会识别；手动选择“活动 / 行程”等性质可覆盖标题识别。准备活动的括号里仅提及未来 deadline，不会把准备日期当成截止日期。

有准确时刻的事项，在剩余 72 小时、明天、当天、两小时内、半小时内、逾期等阶段逐级提醒；只有日期的事项按三天内、明天、今天和日期已过区分，不猜测 23:59。提醒使用已保存的事项日期和时刻，源信息有误时仍需要核对。

桌面卡片合并同轮事项，自动出现时不抢走正在输入的焦点。选择“知道了”确认本阶段；“30 分钟后提醒”会推迟，若实际截止更早，则最迟在截止时再次提醒。勾选完成后停止提醒。改期、删除或重新分类会撤换旧的待发通知。状态在重启后保留。

关闭“桌面弹窗”会保留雷达和已经授权的系统通知。应用运行时每 30 秒检查；退出后仅保留 macOS 已经安排的系统通知。通知声音、横幅和专注模式由 macOS 控制。系统通知滚动安排最近 32 个截止提醒点、最近 15 个时间块的起止提醒，以及一个专注结束提醒。

## 专注与休息

选择 25/5、50/10 或自定义轮次，可以关联当前时间块或自由专注。支持暂停和继续；每轮结束后由你决定休息还是继续，不自动连续开始下一轮。到时间块的结束点会收尾，专注记录只累计实际专注时间。

## 日历和粘贴导入

**日历**：点击“日历同步”，允许系统访问并选择源日历。只读同步最近 30 天到未来 180 天的事件，本地勾选不修改原日历。云端变更需要先到达 macOS 日历，应用运行时监听变更并定时检查。

**邮件和文字**：`⇧⌘V` 打开粘贴识别，粘贴后预览、修正并保存。解析在本机按格式进行，不读取邮箱、不后台监控剪贴板，也不保证理解任意自然语言。

**Canvas**：在“导入与同步 → Canvas 作业与通知”中粘贴多条内容。按课程与作业身份合并，较新的通知发布时间决定截止日期；发布时间不当作 ddl，`Available until` 不当作 `Due`，日期缺失或顺序不明会留待确认。普通资讯和已关闭作业默认不勾选。

`examples/` 中提供虚构邮件、通知和清单，可用于试用。全部链接使用文档示例域名，会议资料均为占位内容。

Canvas 截止订阅可通过 Canvas Calendar Feed 加入 macOS 日历，再在本应用勾选订阅日历。普通公告不包含在日历订阅中；当前应用没有后台登录 Canvas 抓取公告。导出 `.ics` 是一次性快照，之后变更需要重新导出。

## 保存与备份

正常数据位于 `~/Library/Application Support/io.github.amalia6767.wodue/`。在应用中选择“打开数据文件夹”可直接找到。

- `tasks.json`：事项、分类和时间块。
- `focus.json`：专注状态和记录。
- `deadline-reminders.json`：确认与稍后提醒状态。
- 粘贴草稿：留在本地，供下次继续整理。

清单 JSON 备份包含事项、分类和时间块；备份整个数据文件夹才能同时保留专注、提醒和草稿。手动待办和专注记录目前没有跨设备同步。

请用虚构数据复现问题；公开截图和 Issue 前先移除个人日历、邮件原文、会议链接和密码。详见 [隐私说明](PRIVACY.md)。
